# 连锁便利店收银与库存联动管理系统

`AI 问答` `收银与库存联动` `补货入库与盘点全流程` `ECharts 数据可视化` `会员积分与储值`

---

## 一、项目简介

这是一套面向连锁便利店的收银与库存联动管理系统。它解决的是一个很实际的问题：收银是一摊、库存是一摊，卖出去的货要靠人工再做出库、记库存，漏记错记是常事。

这套系统把「卖」和「存」放在同一条业务链路上：收银完成支付的瞬间，销售订单、销售出库、库存扣减、库存流水一气呵成；入库、补货、盘点也全部留痕，每一笔库存变动都能在流水中定位来源。配合会员储值积分、ECharts 经营分析和 AI 业务助手，覆盖便利店日常经营的主要环节。

## 二、核心亮点

| 亮点 | 说明 |
| :--- | :--- |
| 收银与库存联动 | 支付完成即自动生成销售出库单、扣减门店库存、写入库存流水，不需要人工二次出库 |
| 入库 / 补货 / 盘点全流程可追溯 | 入库增加库存、补货审核通过自动生成待入库单、盘点按实际数量调整并记录差异，全部留痕 |
| 库存预警与可视化分析 | 低库存 / 超库存预警、滞销预警（近 30 天销量低于库存 10%），ECharts 饼图、柱状图呈现 |
| 收银经营分析 | 按门店和日期查看销售趋势、支付方式占比、小时订单分布、收银员排行；收银员有个人周报仪表盘 |
| 会员储值与积分 | 储值充值、会员卡支付、积分抵扣（100 积分抵 1 元）、消费赠积分（1 元 1 积分），双流水记录 |
| AI 业务助手 | DeepSeek 大模型 + 本地知识库，流式输出回答，覆盖商品、库存、价格、会员、门店流程等咨询 |
| 多角色权限 | 客户 / 收银员 / 库管员 / 管理员四类角色，菜单按角色展示，数据全程可追溯 |

## 四、核心实现说明

### 4.1 收银与库存联动

收银结算是本系统的核心链路。收银员完成支付后，订单状态更新为已支付，系统同时自动生成销售出库单及出库明细，按订单商品扣减对应门店库存，并写入包含变动前后数量、单价、金额和备注的库存流水。

```text
商品搜索/扫码 -> 加入购物车 -> 绑定会员（可选） -> 支付结算
-> 销售订单 -> 自动销售出库 -> 扣减门店库存 -> 写入库存流水
```

收银业务和库存变化在同一条链路里处理，避免人工重复出库造成的漏记或错记。

### 4.2 入库、补货与盘点的全流程追溯

系统对库存增减建立了可追溯的全流程记录：

| 业务场景 | 系统处理结果 |
| :--- | :--- |
| 销售结算 | 自动创建销售出库单，扣减库存，记录出库流水 |
| 完成入库 | 更新门店商品库存，记录入库流水 |
| 补货审核通过 | 自动生成待入库单与入库明细 |
| 完成盘点 | 以实际数量调整库存，记录盘点差异流水 |

销售、入库、盘点等不同来源的库存变动，都能在库存流水中定位。

### 4.3 库存预警与数据可视化

库存分析模块基于库存记录、商品安全库存和销售数据进行统计：低于最低库存或高于最高库存的商品进入预警清单；近 30 天销量低于当前库存 10% 的商品列为滞销预警。前端使用 ECharts 以分类成本饼图、库存周转率柱状图等形式展示。

### 4.4 收银经营分析

管理员可按门店和日期范围查看经营分析：销售额与订单数趋势、支付方式销售占比、小时订单分布、收银员销售排行。收银员个人仪表盘以周为单位展示交易笔数、交易金额、单均金额、会员订单与 24 小时交易分布，便于班次复盘。

### 4.5 会员储值与积分机制

支持会员绑定、储值充值、会员卡支付、消费记录和积分记录管理。收银支付时会员可用积分抵扣（100 积分抵 1 元）；消费完成后按实付金额取整赠送积分（1 元 1 积分）。积分抵扣与积分获得均生成独立的积分流水。

### 4.6 AI 业务助手

接入 DeepSeek 大模型能力，并将本地 AI 知识库中匹配的内容组合进提问上下文；前端通过流式接口逐步展示回答，支持会话历史管理。主要辅助处理商品、库存、价格、会员积分、会员余额和门店操作流程等常见咨询。

### 4.7 多角色权限与数据追溯

系统按角色展示菜单：客户侧重会员服务和消费查询；收银员侧重收银、订单与会员业务；库管员侧重商品、库存、出入库、盘点和补货；管理员拥有全局基础资料、经营数据、库存数据和 AI 知识库管理能力。销售订单、出入库单、盘点单、库存流水、充值记录和积分记录共同构成业务追溯依据。

## 五、技术说明

- **AI 能力**：DeepSeek 大模型 + 本地知识库检索，流式接口输出，会话历史管理
- **数据可视化**：ECharts（饼图 / 柱状图 / 趋势图 / 分布图）
- **数据库**：MySQL，涵盖基础资料、库存业务、盘点补货、销售会员、AI 能力五大模块共 16 张核心数据表
- **系统形态**：前后端分离的 Web 系统，按角色区分功能菜单
